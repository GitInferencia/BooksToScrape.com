# Scrape Bookstoscrape


Español: Ejemplo de un scrape sencillo

Sitio: Bookstoscrape.

Que hace: Se revisa el portal para obtener la información de nombres de los libros, su costo y rating. 

Se obtiene un resumen:
Total de libros, cuales son los mas populares.
Los 5 mas caros.
Los 5 mas baratos.

Se generan dos archivos de texto que puedo utilizar para analisis sin necesidad de estar conectado

English

Example of a simple scrape

Website: Bookstoscrape.com

What it does: The portal is reviewed to obtain information on book names, their cost, and ratings.

A summary is generated, and two files are created with the information for analysis.
